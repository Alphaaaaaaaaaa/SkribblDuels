# Starter challenge definitions v1

Package: `@skribbl-duels/challenge-definitions`

All starter definitions are restricted to public lobbies (`lobbyType === 0`) and occur at most once per board through the board generator. The generic challenge engine itself does not enforce board uniqueness; the future board/draft layer will enforce it by challenge ID.

## quickscope

- Display name: `Quickscope'd`
- Event: `CORRECT_GUESS`
- Actor: self
- Default condition: `elapsedMs <= 5000`
- Default target: 1
- Evidence: the qualifying `CORRECT_GUESS` event

## better-late-than-never

- Display name: `Better late than never`
- Event: `CORRECT_GUESS`
- Actor: self
- Default condition: `0 <= estimatedTimeAtGuess <= 1`
- Default target: 1
- Evidence: the qualifying `CORRECT_GUESS` event

## cool-number-detected

- Display name: `Cool Number Detected`
- Event: `SCORE_CHANGED`
- Actor: any player in the current public lobby, including self
- Default condition: positive total score divisible by 250
- Score zero never qualifies
- Default target: 1
- Evidence: the qualifying `SCORE_CHANGED` event

## tldr

- Display name: `TL;DR`
- Event: `TEXT_SUBMITTED`
- Actor: self
- Default condition: at least 50 visible Unicode code points after trimming outer whitespace
- Default target: 1
- Evidence: the qualifying `TEXT_SUBMITTED` event

The current telemetry event represents outgoing submission. A later correlation event may strengthen this to server-accepted chat messages if live captures show that own accepted messages are reliably echoed by the server.

## Sandbox instance IDs

- `sandbox-field-quickscope`
- `sandbox-field-better-late-than-never`
- `sandbox-field-cool-number-detected`
- `sandbox-field-tldr`

These IDs exist only in the development inspector. Real matches will use field IDs generated by the match server.
