# Skribbl Slots assets

The v0.66.0 progression registry expects the arcade artwork in this directory:

- `skribbl-slots.gif`, `warning.gif`, `bulb_off.gif`, `bulb_on.gif`
- the 24 outcome GIFs under `slot-icons/`, using the filenames listed in
  `res/progression-assets.template.json`

The build reports missing artwork and keeps an accessible text/emoji fallback.
Gameplay results, costs and rewards never depend on whether artwork is present.
